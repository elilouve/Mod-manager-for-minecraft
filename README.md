# Mod-manager-for-minecraft

This software is made with AI. If you have any suggestion to improve the code or found a bug tell me and I fix it. If you want a new feature ask for it and I see if I can add it.


The software is a mod manager for minecraft, it's a local database where you add a mod from curseforge or modrinth with it's link and then you can download multiple mod at once. You can create list export create category etc. 
For curseforge, you need a free api key and an account on curseforge, all you need to know about the software and how to get the api key is inside the README.txt.
